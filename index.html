Whitespace Mapping

Where in Korean pharma is the unmet opportunity? Diseases with high treated burden but few therapy options, surfaced as quantified whitespace.

Illustrative · Full Data Wired
How this tool works
Method · Data · Gaps
Methodology 4 steps
  1. Aggregate treated patient volume per ICD-10 code (sick_cd) from HIRA utilization data — proxy for disease burden.
  2. Count reimbursed therapy options per indication using ATC class plus reimbursement status; surface manufacturer concentration.
  3. Compute gap score as a function of treated burden, treatment density, and class growth — weighted to highlight under-treated diseases.
  4. Rank diseases by gap score; render bubble matrix and ranked opportunity list. Whitespace = high burden × low treatment density.

Safety & Supply Signals

Cross-market external surveillance across three signal types: shortages (supply-side disruption), label amendments (emerging safety signal), and recalls (quality / regulatory enforcement). KR recall spine wired clean; US shortage + amendment feeds wired via openFDA; KR shortage + label-notification ingestions pending.

Illustrative · 2 KR feeds pending
Mixed · KR recalls live, KR signals pending
How this tool works
Method · Data · Gaps
Methodology 8 steps · 3 feeds
  1. Pull US shortage records from core.shortage (openFDA Drug Shortages, 1,688 rows).
  2. Pull US label amendments from openFDA label via SPL version-history deltas (spl_set_id, effective_time).
  3. Pull KR recall records from core.recall — full detail spine wired clean (KR-side recall feed is the methodological twin of Patent Position).
  4. Pull KR MFDS shortage list + label notifications (both pending small ingestions — public weekly feeds).
  5. Cross-walk by ingredient + ATC across all three signal feeds to identify concurrent multi-signal drugs.
  6. Apply taxonomy classifiers — amendment-type (7 buckets) + recall-reason (6 buckets, applied to KR free-form Korean text).
  7. Aggregate by reason / type / month / sponsor; compute compound-risk pairings (shortage + amendment, shortage + recall, recall + amendment).
  8. Render unified surveillance feed: supply → safety → quality → compounded → KR cross-market views.
Data Inputs · Wired 18 fields · 2 sides
company_name shortage_status reason dates_of_intervention product_type spl_set_id effective_time version_number submission_type recall_date recall_reason recall_command_dt manuf_date lot_no packng_unit open_end_date item_seq entp_tel openFDA Shortages + Label SPL + core.recall

KR MFDS Label Notifications · INGESTION

Same shape as the shortage feed. Public publication of label changes. Net-new ingestion alongside the shortage feed.
Recall Reason Taxonomy · Classifier
recall_reason_category
KFDA recall_reason is free-form Korean. 6-bucket taxonomy is applied (quality defect / labelling / stability / content / contamination / other) — disclose classifier accuracy (~92% on validation sample).
Amendment-Type Classifier

SPL revisions are free-form text. A 7-bucket taxonomy is applied (boxed warning / contraindication / AE expanded / DDI / indication change / dosing / other) — disclose accuracy on validation sample.
Severity Classification

Neither KFDA nor openFDA publishes FDA-style severity classes (Class I/II/III) consistently. Severity proxies: boxed-warning > contraindication > AE-expansion on labels; contamination > quality > labelling on recalls.

The Launch Analogue

Cohort of US→KR launch precedents, weighted by similarity across class, indication, modality, mechanism, orphan status, and US-tier. Load-bearing for the rest of the Launch Pack.

Illustrative · 4 of 6 dims wired
Defensible w/ disclosure
How this tool works
Method · Data · Gaps
Methodology 5 steps
  1. Anchor the subject drug to its US originator via Drugs@FDA application_number and KR trust_item_seq (backend join, never displayed).
  2. Build candidate universe: all KR drugs with a US-originator anchor that completed MFDS filing 2014–present.
  3. Score each candidate across 6 similarity dimensions — class, indication, modality, mechanism, orphan status, US-tier — with prior weights.
  4. Apply dimension confidence multipliers (wired dims = 1.0; unwired dims = 0.0 contribution + flagged).
  5. Rank by weighted similarity; surface top 14 with full dimension breakdown. Cohort feeds Timing & Price forecasts downstream.

Methodology 5 steps

  1. Inherit cohort + weights from LOE Analogue (9 KR LOE precedents · weighted ≥ 0.40).
  2. For each LOE event, build a ±36-month panel: msup_use_amt, tot_use_qty, mx_cprc by month, originator vs generic from is_originator.

How this tool works
Method · Data · Gaps
Methodology 5 steps
  1. Pull current annual revenue: mx_cprc × tot_use_qty × is_originator, aggregated to NHI level via insup_tp_cd.
  2. Extend pre-LOE baseline forward over the 60-month post-LOE horizon using class CAGR (Product Market) as the growth driver.
  3. Pull LOE date from Patent Position (Tool 02) and erosion trajectory from Erosion Curve (Tool 03).
  4. Multiply baseline × erosion trajectory; integrate the gap between baseline-extended and projected actual to get cumulative revenue at risk.
  5. Run sensitivity on LOE-delay scenarios, price floor, volume floor, and BE-filing acceleration.

The Clinical Trial Tracker

Korean MFDS trial approvals × US AACT data, side-by-side. The wire's cleanest cross-market join — same fields wired both sides, no proxy translation. Pipeline signal that underlies the Whitespace v3 unmet-need layer.

Illustrative · Cleanest cross-market join
Defensible · sponsor xwalk disclosure
How this tool works
Method · Data · Gaps
Methodology 5 steps
  1. Pull KR trial records from core.clinical_trial (MFDS Clinical Trial Approval Notification).
  2. Pull US trial records from AACT (Aggregate Analysis of ClinicalTrials.gov) using the same field set.
  3. Cross-walk sponsors via canonical company entity table — handles transliteration (한미약품 ↔ Hanmi) and cooperative-group naming.
  4. Aggregate by phase, sponsor, site, ATC class, and approval cadence over the selected window.
  5. Render side-by-side activity views + sponsor leaderboard + KR site map + cross-market xwalk panel.

clnc_test_sn trial_phase sponsor_nm approval_date instt_nm instt_addr invstgtr_nm appoint_date_trial US AACT · same fields
